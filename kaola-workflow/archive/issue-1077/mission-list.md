# #1077 — Finalize must not mirror unrelated dirty main files into a validated worktree

Narrow reading of the issue. The defect is not an "unrelated file": PR #45 had edited the file, and
the finalize commit's directory attribution (#975) correctly admitted it. The unrelated thing was
main's uncommitted EDIT to a run-owned file, which the Step-8a residue mirror copied over the
worktree's copy with a bare `copyFileSync`. The fix is the content-identity overwrite guard the
project-folder mirror already has (#1054), applied to the residue mirror, in both the read-only
`finalize --check` predictor and the transaction. #837's "classified, never enforced" posture for a
stale receipt is left exactly as it is: once the mirror can no longer overwrite run-authored
content, the transaction can no longer stale its own green receipt through that path.
